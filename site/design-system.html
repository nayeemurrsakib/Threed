Colour

Every role has a light and a dark value, and components only ever name the role. A dashed card borrows another colour in the current theme.

Spacing

A 4px grid with two half-steps. Gaps, padding and margins snap to these values.

Shape

Five radii. Controls are pills, surfaces are softly rounded, dots and avatars are round.

Layout

The page never grows wider than its maximum, and the gutter tightens on smaller screens. Two hairlines frame the page on both sides.

Using the system

  1. Values come from tokens. Colour, size, space, radius and layout live in viewer/tokens.css. Never type a raw pixel value for these.
  2. Repeated text uses a style. Reach for .t-label, .t-meta, .t-caption and friends before writing a new font rule.
  3. Repeated page parts are components. The header and footer live in components/. Edit them there, then run python3 source/build_pages.py.
  4. New components go here. Any new reusable piece is added to this page as a live specimen with its class name, in the same change.
  5. Keep it snapped. After editing CSS, run python3 source/tokenize_css.py viewer/*.css to pull any stray value back onto the scale.
