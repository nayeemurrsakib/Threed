# From first collection to a sellable pack

This folder is the asset-and-viewer review edition. No storefront, checkout, customer license or public deployment has been created.

## Complete in this edition

- 60 distinct object models across six collections.
- Named editable materials and high-detail GLB illustration masters.
- 60 transparent 1024px PNG illustrations, thumbnails and a contact sheet.
- Shared palettes and lighting configurations.
- Pointer response, drag and keyboard rotation, optional turntable.
- Hover-triggered exploded layers, a hold-open control, adjustable layer spacing and authored assembly offsets, plus bound-book hinges and bending pages.
- Editable colors, surface finish, light direction/elevation/strength/fill/warmth and shadow density/softness.
- Edited GLB, 2048px cutout PNG and JSON recipe downloads.
- Plain HTML embedding component and original button kit.
- Reproducible model generation source and structural validation script.

## Remaining release decisions and checks

1. **Curation:** The Studio camera is the approved benchmark. The book is the next individual motion study. Finish and review each remaining silhouette, material, seam, underside and natural interaction before including it in a commercial selection. Do not use the broad construction pass or a passing script to call all 60 objects curated. Remove weak objects from a release rather than filling a count.
2. **Brand:** The supplied product name and smiling identity are threed®. Finalize the seller identity and any release checks before selling.
3. **Compatibility:** Test representative models in your chosen Blender version, a standard glTF viewer, Three.js and any promised website builder. Publish only the compatibility you actually test. This edition was built around its included custom viewer.
4. **Independent validation:** Run the Khronos glTF Validator before public release. The included checks cover binary structure, buffers, positions, normals, indices, bounds, materials and renders; they do not replace the complete specification validator.
5. **Browser and device coverage:** Test Safari, Chrome, Firefox, touch devices and lower-power hardware. Assess time to first object, frame rate and GPU memory with the intended integration. The included viewer bounds pixel ratio and pauses rendering while hidden or offscreen, but needs a wider device matrix before a support promise.
6. **Buyer deliverables:** Offer a small free sampler, the full PNG pack, and an interactive/source tier. Keep the exact file count, image resolution and included integrations explicit. These are product tier ideas, not validated demand or pricing research.
7. **License:** Decide personal/commercial scope, seat and client rules, redistribution restrictions and source-file tier; replace the customer-license draft with your finalized terms.
8. **Listing:** Use the real contact sheet and a short recording of recoloring, moving the light and cursor response. State that PNG files are static and GLB files need a viewer for interaction.
9. **Delivery:** Test a fresh unzip on another machine, a different local port, downloads, missing-model errors and paths with spaces. Include the guide and version identifier in the customer archive.
10. **Support:** Establish a contact address, a short setup FAQ, update policy and bug-report path before publishing.

Do not inflate the object count by multiplying palettes, light rigs, camera angles or output file formats. The present collection has 60 unique base models.
