# Customer license decisions / not active terms

This is a product-planning template for the seller. It does not impose a customer license on the creator of this pack and should not be shipped as finalized legal terms.

Fill in the seller's legal identity, product name, version, effective date and customer support address. Then decide:

| Decision | Proposed product rule to review |
| --- | --- |
| End-product use | Allow personal and commercial websites, apps, presentations, videos and marketing deliverables. |
| Modification | Allow recoloring, relighting, animation, mesh edits and derived renders. |
| Seats | Decide whether one purchase covers one person, one team or a fixed seat count. |
| Client work | Decide whether the buyer can use the assets in client projects and what files may transfer to a client. |
| Redistribution | Distinguish embedding within an end product from reselling or sharing the standalone assets or a competing pack. |
| Editable source | Decide which tier includes the procedural recipes and whether those sources have separate redistribution rules. |
| Stock/template products | Decide whether templates, themes and builder marketplaces need an extended license. |
| Updates | State whether the purchase includes only this version or later versions as well. |
| Support | Describe supported files, applications and response channels without promising untested compatibility. |
| Third-party dependencies | The supplied viewer has no external libraries. Review any additional fonts, HDRIs, textures or libraries you introduce before release. |

Use finalized terms that fit the actual product and sales channel. Keep this planning document out of the final customer package once those terms are ready.
